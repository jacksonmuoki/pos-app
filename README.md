# POS — Point of Sale System

A modern, responsive PHP and MySQL/MariaDB Point of Sale application for retail operations, cashier management, sales tracking, receipts, reporting, and PayHero-powered M-Pesa STK Push integration.

## Features

- Role-based staff authentication
- Cashier and sales workflows
- Product and order management
- Cash and M-Pesa payment workflows
- PayHero STK Push integration
- Receipt generation and printing
- Administrative tools and reporting
- Responsive green-themed interface

## Technology Stack

- PHP
- MySQL / MariaDB
- HTML, CSS, JavaScript
- XAMPP
- PayHero and M-Pesa

## Local Development

1. Clone the repository.
2. Place it in your local PHP web server directory.
3. Start Apache and MySQL.
4. Configure the database and application settings.
5. Import the appropriate database schema.
6. Open the application using its configured local URL.

## Security

Never commit database passwords, PayHero credentials, API keys, tokens, or production environment files. Verify payment transactions through trusted provider callbacks or verification mechanisms.
